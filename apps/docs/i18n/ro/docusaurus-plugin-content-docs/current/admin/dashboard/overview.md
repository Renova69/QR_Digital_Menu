# Prezentare Generală Tablou de bord

Tabloul de bord este spațiul de lucru al proprietarului și managerului pentru configurarea și operațiunile restaurantului.

În funcție de rol, plan și funcțiile activate, acesta oferă acces la editarea meniului, mese și coduri QR, comenzi live, plăți, rezervări, feedback, analize, personal, stații de imprimantă, setările restaurantului și gestionarea abonamentului.

Porțile de funcții pot ascunde secțiuni care nu sunt incluse în abonamentul efectiv al restaurantului. Dispozitivele personalului și ale rolurilor pot avea, de asemenea, vizualizări operaționale mai restrânse decât proprietarii și managerii.
