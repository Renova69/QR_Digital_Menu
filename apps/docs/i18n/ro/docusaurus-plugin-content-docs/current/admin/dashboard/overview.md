# Prezentare generală a tabloului de bord

Tabloul de bord este spațiul de lucru al proprietarului și managerului pentru configurarea și operațiunile restaurantului.

În funcție de rol, plan și funcțiile activate, acesta oferă acces la editarea meniului, mese și coduri QR, comenzi live, plăți, rezervări, feedback, analize, personal, stații de imprimantă, setările restaurantului și gestionarea abonamentelor.

Porțile de funcții pot ascunde secțiuni care nu sunt incluse în abonamentul efectiv al restaurantului. De asemenea, rolurile de personal și dispozitiv pot avea vizualizări operaționale mai restrânse decât proprietarii și managerii.
