# Preluarea comenzilor prin POS

1. Deschideți `/staff/pos` pe un dispozitiv autorizat al personalului.
2. Selectați masa relevantă sau punctul de servire.
3. Adăugați elemente de meniu, cantități, opțiuni și note acceptate.
4. Revizuiți comanda și trimiteți-o.
5. Confirmați că apare în vizualizarea operațională corespunzătoare.

Acțiunile privind starea comenzii urmează fluxul de lucru al restaurantului și permisiunile rolului conectat. Instrumentele de plată pot accepta decontarea completă, parțială sau detaliată atunci când funcțiile corespunzătoare și furnizorul sunt activate.

Nu creați o a doua comandă doar pentru că un răspuns de rețea este lent. Verificați masa și istoricul comenzilor înainte de a reîncerca.

*(Pentru pași detaliați privind comanda la masă, opțiunile pentru preparate și închiderea notei, consultați [Ghidul POS pentru ospătari](/guides/operations/waiter-pos))*
