# Gestionarea rezervărilor

Operațiunile de rezervare arată rezervările primite și starea lor curentă. În funcție de starea curentă, personalul autorizat poate confirma, refuza, marca sosirea, finaliza, anula sau înregistra o neprezentare.

Când confirmarea manuală este activată, examinați data solicitată, ora, dimensiunea grupului, detaliile de contact și notele înainte de a confirma sau refuza. Renova trimite notificări configurate oaspeților pentru modificările de stare acceptate.

Oaspeții pot utiliza linkul de gestionare securizat din comunicarea lor de rezervare pentru a revizui acțiunile acceptate. Mențineți programul de funcționare și capacitatea restaurantului actualizate, astfel încât disponibilitatea publică să rămână exactă.

*(Pentru ghidul complet de rezervări, consultați [Rezervări de mese](/guides/customer-experience/reservations))*
