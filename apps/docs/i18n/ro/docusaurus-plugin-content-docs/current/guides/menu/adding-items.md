# Adăugarea Articolelor din Meniu

1. Deschideți **Tablou de bord → Editor Meniu**.
2. Selectați o categorie existentă sau creați una.
3. Adăugați un articol și introduceți numele, descrierea și prețul acestuia.
4. Adăugați o imagine și informații despre alergeni, atunci când este cazul.
5. Salvați articolul, apoi previzualizați meniul public.

Utilizați controlul de disponibilitate pentru a ascunde temporar un articol epuizat fără a-l șterge. Păstrați descrierile concise și verificați prețurile înainte de publicare.
