# Adăugarea elementelor în meniu

1. Deschideți **Tabloul de bord → Editor meniu**.
2. Selectați o categorie existentă sau creați una nouă.
3. Adăugați un articol și introduceți numele, descrierea și prețul acestuia.
4. Adăugați o imagine și informații despre alergeni, dacă este cazul.
5. Salvați articolul, apoi previzualizați meniul public.

Utilizați controlul disponibilității pentru a ascunde temporar un articol epuizat fără a-l șterge. Păstrați descrierile concise și verificați prețurile înainte de publicare.
