# Gestionarea Categoriilor

Categoriile grupează articole similare, cum ar fi antreuri, feluri principale, deserturi și băuturi.

## Crearea și Ordonarea Categoriilor

1. Deschideți **Editor Meniu** și creați o categorie.
2. Introduceți numele și descrierea opțională a acesteia.
3. Reordonați categoriile și articolele pentru a controla modul în care acestea apar oaspeților.

Dezactivați vizibilitatea unei categorii pentru a elimina întreaga secțiune din meniul public fără a-i șterge articolele. Acest lucru este util pentru secțiunile sezoniere sau indisponibile temporar.
