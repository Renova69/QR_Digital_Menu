# Gestionarea categoriilor

Categoriile grupează elemente similare, cum ar fi aperitive, feluri principale, deserturi și băuturi.

## Creați și ordonați categorii

1. Deschideți **Editor meniu** și creați o categorie.
2. Introduceți numele său și descrierea opțională.
3. Reordonați categoriile și articolele pentru a controla modul în care apar oaspeților.

Dezactivați vizibilitatea unei categorii pentru a elimina întreaga secțiune din meniul public fără a șterge elementele sale. Acest lucru este util pentru secțiunile sezoniere sau temporar indisponibile.
