# Încărcarea Imaginilor pentru Meniu

Renova acceptă imagini JPEG și PNG pentru articolele din meniu de până la 5 MB.

## Încărcarea unei Imagini

1. Deschideți un articol în **Editor Meniu**.
2. Selectați controlul de imagine al acestuia și alegeți un fișier JPEG sau PNG.
3. Salvați articolul și verificați rezultatul în previzualizarea meniului public.

Utilizați fotografii clare, încadrate consecvent și comprimați imaginile sursă mari înainte de încărcare. Evitați plasarea textului esențial în interiorul unei imagini, deoarece poate fi dificil de citit pe ecrane mici.
