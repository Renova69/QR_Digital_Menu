# Experiența de Finalizare a Comenzii

Finalizarea comenzii arată coșul oaspetelui, cantitățile, opțiunile selectate, totalul și câmpurile solicitate de configurația curentă de comandă a restaurantului.

Oaspeții pot revizui destinația atașată sesiunii lor QR și pot adăuga note acceptate sau cereri speciale înainte de trimitere. Alegerile de plată apar doar atunci când restaurantul le-a activat și configurat.

După trimitere, Renova afișează starea relevantă de confirmare a comenzii sau a plății. Personalul ar trebui să testeze acest flux complet după modificarea setărilor meniului, comenzilor sau plăților.
