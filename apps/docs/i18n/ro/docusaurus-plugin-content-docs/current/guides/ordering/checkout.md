# Experiența de finalizare a comenzii

Finalizarea comenzii afișează coșul oaspetelui, cantitățile, opțiunile selectate, totalul și câmpurile necesare conform configurației actuale de comandă a restaurantului.

Oaspeții pot revizui destinația atașată sesiunii lor QR și pot adăuga note suportate sau cereri speciale înainte de a trimite. Opțiunile de plată apar doar atunci când restaurantul le-a activat și configurat.

După trimitere, Renova afișează starea relevantă de confirmare a comenzii sau a plății. Personalul ar trebui să testeze acest flux complet după modificarea setărilor meniului, comenzilor sau plăților.
