# Cum Funcționează Comenzile Online

Când comenzile sunt activate pentru restaurant și punctul de servire, oaspeții pot trimite comenzi din meniul public fără a instala o aplicație.

## Fluxul Oaspetelui

1. Oaspetele scanează un cod QR.
2. Renova deschide meniul și asociază sesiunea cu punctul de servire.
3. Oaspetele alege articole și opțiuni, apoi revizuiește coșul.
4. Oaspetele finalizează fluxul disponibil de finalizare a comenzii sau de plată.
5. Comenzile eligibile apar în vizualizările operaționale ale restaurantului în timp real.

Personalul poate urmări progresul comenzii în tabloul de bord, POS sau afișajul din bucătărie, în funcție de rolul lor și de funcțiile activate.
