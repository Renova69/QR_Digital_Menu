# Преглед на дигиталното меню

Гостите отварят вашето удобно за мобилни устройства меню чрез сканиране на QR код на маса или точка за обслужване. Не се изисква инсталиране на приложение.

## Основни възможности

- Организирайте артикулите във видими, подредени категории.
- Добавете имена, описания, цени, изображения и информация за алергени.
- Маркирайте артикулите като недостъпни, без да ги изтривате.
- Представете преведено съдържание на менюто, когато са конфигурирани преводи.
- Приложете брандирането на ресторанта към публичното меню.
