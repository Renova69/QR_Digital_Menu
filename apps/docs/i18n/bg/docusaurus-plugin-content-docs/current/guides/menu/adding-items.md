# Добавяне на артикули в менюто

1. Отворете **Dashboard → Menu Editor** (Табло за управление → Редактор на меню).
2. Изберете съществуваща категория или създайте нова.
3. Добавете артикул и въведете неговото име, описание и цена.
4. Добавете изображение и информация за алергени, когато е приложимо.
5. Запазете артикула, след което прегледайте публичното меню.

Използвайте контролата за наличност, за да скриете временно разпродаден артикул, без да го изтривате. Поддържайте описанията кратки и проверявайте цените преди публикуване.
