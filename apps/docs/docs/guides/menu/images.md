# Uploading Menu Images

High-quality images are one of the biggest drivers of orders. Studies show menu items with photos receive up to 3× more orders.

## Recommended Specs

| Property | Recommendation |
|---|---|
| Format | JPG or PNG |
| Dimensions | Minimum 800×800px (square) |
| File size | Under 2MB |
| Background | Clean, well-lit, neutral background |

## How to Upload

1. Open a menu item for editing.
2. Click the image placeholder or drag and drop a file onto it.
3. Crop if needed, then click **Save**.

## Tips

- Natural lighting produces the best food photos.
- Use a consistent style across all items for a professional look.
