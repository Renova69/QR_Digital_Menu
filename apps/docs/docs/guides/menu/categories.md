# Managing Categories

Categories organize your menu into logical sections (e.g., Starters, Mains, Drinks).

## Creating a Category

1. In **Menu Editor**, click **+ Add Category**.
2. Enter a name and optional description.
3. Drag categories to reorder them — the order shown here is the order guests see.

## Reordering Items Within a Category

Drag and drop items within any category to control their display order.

## Hiding a Category

Toggle a category's visibility off to hide the entire section from guests without deleting anything. Useful for seasonal menus.
