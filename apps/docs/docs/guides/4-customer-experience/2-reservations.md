# Table Reservations

*(Available on PROFESSIONAL and ENTERPRISE tiers)*

The platform includes a complete Table Reservations system, allowing your customers to book tables online while you manage capacity effortlessly from the dashboard.

## Booking Experience

Customers can access your booking page via a direct link or your public menu. The booking flow includes:
- **Date & Time Selection**: Customers select from your available slots.
- **Party Size**: Enforces your venue's maximum capacity rules.
- **Guest Preferences**: Customers can specify seating preferences (e.g., Terrace, Main Dining), dietary requirements, and accessibility needs.
- **Self-Service Management**: After booking, customers receive an SMS notification (powered by Twilio/SIM gateway) and a link to a confirmation page. From there, they can independently cancel or modify their booking without having to call your restaurant.

## Dashboard Management

For staff, the Reservations tab in the dashboard provides a powerful calendar view.

- **Availability Calendar**: See all bookings at a glance.
- **Seating Zones**: Configure your venue's zones (e.g., Bar, Patio) and set maximum capacities for each.
- **Duration Configuration**: Set the standard duration for a reservation (e.g., 90 or 120 minutes) so the system can accurately calculate when a table will be free again.
- **Blackout Dates**: Easily block off dates for private events or holidays where you don't want to accept online bookings.

## Real-Time Sync
Just like orders, reservation statuses synchronize in real-time across all dashboard instances. If a host updates a reservation to "Seated" on a tablet at the door, the manager checking the dashboard in the back office sees it instantly.
